Public-domain naval plans and recognition drawings are suitable historical references for original reconstructions. Detailed source-based work is underway where suitable licensed downloadable art is unavailable. No candidate's images or meshes have been copied into the project merely because its listing mentions a permissive license.

The two downloaded ships use the [AllenAI Objaverse public distribution](https://huggingface.co/datasets/allenai/objaverse), which preserves each object's individual license. Their official Sketchfab API records were read at `/v3/models/<id>` and each original GLB embeds the same author, original page and CC-BY-4.0 attribution. `licensed-ships.json` pins direct public download URLs and SHA-256; companion model source files include each embedded image hash. The optional importer verifies those hashes and writes self-contained runtime GLBs, retaining all original texture bytes. No login or access-control bypass was used.

Native precision audit: importing the initial Samidare exposed 42 front-face/normal mismatches in Unreal, which were independently reproduced using Float32 centimetre positions and `FPackedRGBA16N` normals. Most were source winding mistakes hidden by an area-dependent tolerance; source winding is now corrected by sign. The 14 remaining orientation-unstable slivers have maximum altitude 1.638 micrometres (0.671 position ULP) and maximum area 0.000757 cm². They carry no resolvable surface detail. Exact repair counts and bounds are embedded in each normalized GLB and its source sidecar. The native test tolerance has not been relaxed; an independent stored-GLB regression check reproduces the native coordinate/packing precision.

Additional public-mirror candidates, not yet imported: `martyn169`'s [Georgios Averof](https://sketchfab.com/3d-models/d31c51574a864ff08fa0618e91b47c31) (687k triangles), [SMS Emden 1908](https://sketchfab.com/3d-models/01036e2cd38149af8e1d786d4a1097d9) (728k), and [Espana](https://sketchfab.com/3d-models/226132928f29407c8d80b9f372b4958f) (1.14M). The official API labels these CC Attribution, but artist provenance, dimensions, historical fit, original geometry and texture quality still require inspection. Emden 1908 is not the later 1925 cruiser in the current catalog.

`martyn169`'s [Surcouf](https://sketchfab.com/3d-models/eb728c76b39f462683fa8987f55da59a) was downloaded to the ignored build candidate cache only. Its embedded attribution confirms CC-BY-4.0, but the source is untextured material-color geometry with SketchUp edge-line primitives. It does not meet the requested close-up art quality and is not included in active assets or the gallery. The current catalog uses the name Surcouf within the fictional `ecole_ss28` submarine aggregate alongside several unrelated named vessels; there is no exact historical class mapping to replace.

Mapping recommendations: keep Bismarck bound to an explicitly historical Bismarck demo/review identity and Samidare to its own review identity until a real Shiratsuyu-class entry exists. The fictional German 1930s battleships and Japanese destroyer programs have different designs and armament. A name similarity or broad ship type is not sufficient to reuse these artist meshes. Searches for the catalog's Hood, Queen Elizabeth, Nelson, Nagato and Kongo found only gated models, simplified small-scale print models, or uploads identified as commercial-game extractions; none was added.

Bow-direction verification uses the stored mesh rather than a ship's mast location. Bismarck's source-positive-X end has the narrower, raised Atlantic bow; its tall aft mainmast initially made the opposite interpretation plausible. The import therefore preserves source +X rather than rotating the ship 180 degrees. The regression checks each detailed model's actual hull end widths and, where appropriate, forecastle height. Native fixed-camera captures after this correction show Bismarck and Samidare pointing the same way, with successful native ray picking.
