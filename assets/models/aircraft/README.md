# Tactical aircraft

Six original stored GLBs provide fighter, dive-bomber and torpedo-bomber silhouettes in blue-grey A and green B recognition liveries. Smooth shaped fuselages, closed airfoil wings, tailplanes, glazed/framed canopies, radial engines, three-blade propellers, gear fairings and role-specific stores are geometry. These are representative WWII carrier aircraft, not exact Wildcat/Dauntless/Devastator/Zero/Val/Kate reconstructions or national identifications for every campaign.

The game reads these self-contained files directly. `node assets/models/aircraft/author.mjs` regenerates them only when geometry is edited. Coordinates use metres, X forward, Y up, Z span. All geometry/materials are original project work; no third-party model license applies.

Native instancing bounds visible aircraft. A formation can represent more actual planes than it draws; the group label and tactical roster retain the real surviving count. Flight centroids follow recorded simulator positions. Altitude, local formation spacing and bank/attack pose illustrate the aggregate flight and do not add combat outcomes, measured historical trajectories or individual-aircraft simulation.
