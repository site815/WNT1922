WNT1922 - Windows portable build

Download and double-click WNT1922-0.19.0-portable-win-x64.exe. It contains the
complete game and runtime, temporarily unpacks its files and starts WNT1922.
No installation, administrator rights, Node.js or separate browser is required.
The window opens maximized; Alt-Tab works normally. The campaign menu can switch
fullscreen mode. Allow about 1 GB of free temporary storage.

Saves: %APPDATA%\WNT1922\saves\campaign.json
The previous valid save is campaign.backup.json. Export save file in the game
also produces a portable copy. Temporary game files are removed after normal
shutdown; these saves remain. Save compatibility between beta versions is not
guaranteed. Start a new campaign for 0.19.0.

This beta is not code-signed. Windows may display an unknown-publisher warning.
Verify the download's SHA-256 against the accompanying checksum from the publisher.

Credits are available in the game and THIRD_PARTY_NOTICES.md. Electron's LICENSE
and LICENSES.chromium.html must remain in the package. Political boundaries are
approximate historical game overlays made from public-domain Natural Earth data.

Bug reports: include the version shown at the top left, campaign and nation,
steps to reproduce, expected/actual behavior, and an exported save if useful.
The game does not send automatic telemetry or upload your campaigns.
