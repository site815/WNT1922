# Distribution asset audit — 0.18.1

Reviewed 11 September 2026. Scope: all game asset files, generated maps, browser imports, downloadable runtime and files selected for the Windows package. Source URLs, licenses, byte counts and SHA-256 digests are in `game/assets/third-party-manifest.json`. `tools/audit-assets.mjs` rejects unreviewed asset changes and missing credits; `tools/verify-package.mjs` rejects unexpected application files.

| Material | Finding and release treatment |
| --- | --- |
| Political map | Replaced with Natural Earth 1:50m map units 5.1.1 (public domain), plus independently authored approximate historical game overlays. The old generator and polygons are not used. |
| Coastline | Natural Earth 1:110m land (public domain). Local bytes matched a fresh copy from the publisher's repository. |
| 15 music recordings | Kevin MacLeod, CC BY 4.0. Every local MP3 matched a fresh original download by SHA-256; all titles and ISRCs matched the composer's catalog. Preserve attribution and license links. Verification record: `licenses/music-verification.json`. |
| Sound effects | Generated by WebAudio; no downloaded samples. |
| Icons and graphics | Authored SVG/CSS and projection code; no downloaded icon pack or UN map artwork. |
| Fonts | Operating-system fonts; no font binaries or remote font services. |
| Ship/aircraft/scenario data | Factual specifications and authored scenario text. Research citations remain; source scans are excluded. |
| Windows runtime | Official, unmodified Electron 44.3.0 archive verified against the release's SHA-256. Runtime license files and corresponding source information accompany the package. |
| Development tools | Git, GitHub CLI, Python/map libraries and browser testing tools are not shipped with the game. |

Natural Earth's [terms](https://www.naturalearthdata.com/about/terms-of-use/) permit commercial adaptation and redistribution. The composer's [licensing page](https://incompetech.com/music/royalty-free/licenses/) supplies CC BY 4.0 credits; [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) permits commercial use with its attribution and notice conditions. These conditions remain in force independently of any license chosen for the game itself.

Executable assembly uses a file allowlist. It excludes retired restricted map archives, Lloyd's register scans and page images, saves, credentials, test fixtures, screenshots and local tools. Git starts with the reviewed source and asset set; restricted source material is not introduced into Git history.

The audit found no noncommercial-only game asset in the new distributable. It records provenance and the applicable conditions rather than promising that third-party rights can never be challenged. Historical-map accuracy is a separate limitation: the new borders are coarse game approximations.
