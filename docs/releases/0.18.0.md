# WNT1922 0.18.0 — Windows beta

Extract the complete Windows ZIP and run **WNT1922.exe**. No separate Node.js or browser installation is needed. Keep every file, including DLLs, resources, licenses and runtime source archives.

- Replaced the restricted political map with public-domain Natural Earth geometry and independently authored approximate historical overlays.
- Reverified all 15 music recordings and included their CC BY 4.0 attribution and file hashes.
- Added the Windows desktop package, maximized normal window, isolated simulation worker, and save-on-close behavior.
- Saves live in `%APPDATA%\WNT1922\saves`, outside the extracted game folder.
- Added a private source repository and a Windows build/test workflow.

Validation: 187 release tests passed. Both campaign dates passed executable playthroughs covering orders, purchases, funding, map, audio and save/reopen. The package has an asset audit, per-file manifest and ZIP SHA-256.

Start a new campaign for this version. The build is unsigned; Windows may identify it as an unknown publisher. Historical borders are approximate. No storefront has been published and the original game source has not been licensed as open source.
