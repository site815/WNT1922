# WNT1922 0.18.2 — catalog review build

Extract the complete Windows x64 ZIP and open **WNT1922.exe**. This is the portable test build. Start a new campaign; save format 10 replaces earlier saves. Keep the DLLs, resources, notices and runtime source archives with the executable.

- Naval commands use one scrolling list. Fleet marker offsets remain stable when neighboring formations or redraw order change.
- War warnings conceal the outbreak date. The warning and actual declaration still pause and show their diplomatic dispatches.
- Monthly economic growth changes base gold and industry output. Resource hovers expose growth inputs and actual monthly reserve changes.
- Civilian merchant fleets receive small monthly deliveries outside naval orders. Naval support designs use 1922, 1932 and 1942 generations; Japan's 1936 Standard Maru tender retains its combined role.
- All fourteen current opening catalogs are available in the source review document, with the proposed operational-air rules. Aircraft roster changes and operational-air warfare are awaiting the requested catalog review; they are not implemented in this release.

Original game source remains private. Public-domain map geometry, commercially redistributable music and runtime source/license materials are unchanged from 0.18.1. The beta executable is unsigned.
