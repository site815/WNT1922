# government aviation — data and balance

Each service uses the latest distinct model for each role. Grounded superseded airframes retire on the next daily update when their successor becomes available. Aircraft already in flight or aboard transports remain real and vulnerable; they retire on the first daily update after arrival. Retirement is recorded separately from losses. Replacement aircraft still require ordinary materials and industry, are manufactured at the monthly service intake, and travel from the home warehouse through the same reinforcement routes. No free in-place conversion occurs. Edit the JSON block directly; the game reads it at startup.

```json game-data
{
  "GOVERNMENT_SHARES": {
    "maritime_patrol": 0.25,
    "maritime_strike": 0.25,
    "strategic_bomber": 0.35,
    "fighter": 0.15
  }
}
```
